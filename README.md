# Спільнота

Суспільна мережа в стилі класичних соцмереж 2013 року. Повністю децентралізована — без жодного сервера: дані живуть у git-репо учасників на GitHub, а стрічку збирає браузер кожного користувача.

Жива версія: **https://fil-m.github.io/spilnota/**

## Як це працює

У **кожного користувача свій репозиторій** `spilnota-<нік>`, який створюється автоматично при вході. Всі дані — у git-репо учасників, запис через GitHub Contents API, читання з ETag-кешем (304 не витрачає rate limit).

### Вхід
1. Кнопка «Створіть токен на GitHub» → GitHub відкриває форму токена (галочка `repo` вже стоїть)
2. Користувач копіює токен і вставляє його → браузер створює репо `spilnota-<нік>` автоматично
3. Токен зберігається **тільки в браузері власника** — нікуди не передається (застосункам передається лише нік)

### Дані (у репо користувача `spilnota-<login>`)
| Файл | Що зберігає |
|---|---|
| `data/profile.json` | профіль (ім'я, аватар, статус, місто, приватність проектів) |
| `data/wall.json` | пости користувача |
| `data/likes.json` | лайки, які поставив користувач |
| `data/comments.json` | коментарі користувача |
| `data/outbox/<peer>.json` | вихідні повідомлення (діалог з <peer>) |
| `data/groups.json` | реєстр груп |
| `data/groups/<id>.json` | метадані групи (в адміна) |
| `data/gwall/<id>.json` | стіна групи |
| `data/pages.json` | категорії сторінок (навігатор) |
| `data/modules.json` | декларації модулів спільноти |

### Як знаходимо учасників
Кожне репо має мітку `spilnota`. Браузер робить пошук по GitHub (`topic:spilnota`), отримує список репо учасників (кеш 5 хв) і читає їхні файли.

### Діалоги — «як пошта»
- Олена пише Петру → файл лягає в **репо Олени** `data/outbox/petro.json`
- Петро читає: у кожного учасника дивиться `data/outbox/petro.json` — і бачить листи для себе
- Кожен зберігає тільки свої вихідні повідомлення

## Модулі

| Модуль | Що вміє |
|---|---|
| Профіль | моя сторінка, редагування, фото-аватар (фото → частинки), сторінки користувачів |
| Стіна | пости, лайки, коментарі; вбудовування відео з посилань (YouTube, TikTok, Spotify, ...) |
| Повідомлення | приватні діалоги |
| Люди | список учасників |
| Групи | приватні (вступ через заявку адміну) і загальні (вступ миттєвий), адмінка |
| Мої проекти | репо з GitHub: фільтри, приховування, ручний порядок |
| Сторінки | навігатор задеплоєних сторінок з категоріями |
| Застосунки | каталог сторінок учасників, відкриваються у вбудові з передачею ніка |
| Налаштування | модулі, теми, шрифти, модулі спільноти |

**Модулі спільноти (v23):** будь-який учасник може опублікувати код модуля у своєму репо (`data/modules.json` + JS-файл). Інші бачать версію в Налаштуваннях і перемикаються між базовою і чужими версіями. Попередження показується при кожному переході на чужий код.

## Структура коду

Код розбито на шари та модулі (порядок завантаження важливий):

```
index.html
css/
├── base.css        # змінні тем, шапка, каркас, меню, картки, форми, модалка
└── modules.css     # стилі окремих модулів (стіна, групи, проекти, застосунки, ...)
js/
├── config.js       # константи, теми, шрифти, MODULE_DEFS, налаштування (cfg)
├── utils.js        # утиліти: $, esc, base64, час, toast
├── api.js          # транспорт GitHub Contents API + пошук учасників
├── data.js         # стан і синхронізація даних: стіна, лайки, коментарі, діалоги, групи
├── community.js    # модулі спільноти (SPILNOTA.register) — чужий код з репо учасників
├── embed.js        # вбудовування відео/аудіо з посилань
├── render.js       # роутер, навігація, renderScreen, базова стіна
├── render-groups.js
├── render-projects.js
├── render-pages.js
├── render-apps.js
├── render-avatar.js
├── render-profile.js
├── render-settings.js
├── actions.js      # дії: пости, лайки, коментарі, повідомлення, вхід
└── app.js          # поллінг і старт застосунку
```

## Безпека
- ✅ Немає спільного токена — кожен володіє тільки своїм
- ✅ Ніхто не може писати в чуже репо
- ✅ Повний архів у кожного в git
- ⚠️ Репо публічні → «приватні» діалоги видно тому, хто спеціально піде дивитись у репо
- ⚠️ Код модулів спільноти виконується у браузері і бачить токен — вмикати лише перевірених авторів

## Локальний запуск
```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Тестування
E2E-тести без репо: Python-мок GitHub API + Playwright. Скрипти в `/tmp/test-*.js` (стіна, редагування, сторінки, аватар, вбудовування, діалоги, групи, застосунки, модулі — разом ~150 перевірок).

## Деплой
- GitHub Pages: Settings → Pages → Deploy from branch → main / root
- Cache-busting: усі ресурси в `index.html` мають `?v=N` — інкрементувати N при кожному релізі
