# Спільнота

Суспільна мережа в стилі **ВК 2013**. Працює без сервера — усі дані живуть у JSON-файлах цього репозиторію, синхронізація через GitHub Contents API (поллінг + merge по sha).

## Модулі
- **Профіль** — реєстрація з ніком та емодзі-аватаром, статус, місто, «про себе»
- **Стіна (блог)** — пости, лайки, коментарі
- **Приватний чат** — діалоги, окремий файл на пару `data/dialogs/<a>__<b>.json`

## Дані
| Файл | Що зберігає |
|---|---|
| `data/profiles.json` | профілі користувачів |
| `data/wall.json` | усі пости стіни |
| `data/dialogs.json` | індекс діалогів (останнє повідомлення) |
| `data/dialogs/<a>__<b>.json` | повідомлення діалогу |

## Локальний запуск
```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Як це працює
1. Клієнт читає JSON з репо через GitHub Contents API
2. Кожні 5 секунд — поллінг активного екрана
3. Запис: читання свіжого sha → merge → PUT → retry при 409
4. Токен із `repo`-скоупом зашитий у клієнт (XOR-обфускація) — тільки для власника
